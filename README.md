# 🛡️ Insurance Customer Response Prediction

## Project Overview

This project predicts whether a customer will respond positively to a vehicle insurance offer using Machine Learning techniques.

## Business Problem

Insurance companies spend significant resources on marketing campaigns. Predicting customer response helps improve targeting, reduce marketing costs, and increase conversion rates.

## Dataset Features

- Gender
- Age
- Driving License
- Region Code
- Previously Insured
- Vehicle Age
- Vehicle Damage
- Annual Premium
- Policy Sales Channel
- Vintage

## Tools & Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
- Power BI

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Data Preprocessing
5. Model Training
6. Model Evaluation
7. Dashboard Development

## Models Used

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Business Impact

The model helps identify customers most likely to purchase insurance products, enabling targeted marketing and improved campaign effectiveness.
